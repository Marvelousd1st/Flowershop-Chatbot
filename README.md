# Bloom & Blossom — Flower Shop Chatbot Demo

A responsive, static flower shop website with a sample chatbot interface. Created as a portfolio-friendly demonstration for a no-code AI chatbot project.

## Features

- Flower shop landing page and sample bouquet cards
- Chat panel with suggested questions
- Sample responses about bouquet choices, prices, occasions, flower care, and delivery
- Responsive layout for mobile and desktop
- No build tools or server required

## Run locally

Download or clone this repository and open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages section.

## Important project note

This is a standalone simulated chatbot. It is **not connected to IBM watsonx Assistant** and does not use a live AI model. Its sample answers are defined in `script.js`. Replace the sample content and prices with your own project details.

If you have exported your original IBM assistant, keep its original JSON or ZIP backup in the repository only if you are comfortable making its contents public. Review it first and remove API keys, credentials, customer data, or other private information. You can also keep the original backup privately on your computer and upload only a sanitized copy.

## Suggested portfolio description

Built a no-code customer-support chatbot for a flower shop using IBM watsonx Assistant as part of the Coursera course *Building AI-Powered Chatbots Without Programming*. This repository includes a standalone website prototype that demonstrates common customer questions and sample responses. The static prototype is separate from the original IBM assistant runtime.
