# 🌸 Flower Shop Chatbot — IBM watsonx Assistant

Hi! Welcome to my Flower Shop Chatbot project.

I built this project as part of the **IBM Building AI-Powered Chatbots Without Programming** course on Coursera. I used IBM watsonx Assistant to create a virtual assistant named **Florence**, designed to help customers get information about a flower shop and find flowers for different occasions.

I wanted to explore how chatbots can make customer service easier and more interactive, even without writing all the chatbot logic from scratch.

## 💐 What Florence Can Do

Florence is designed to help customers with things like:

- **Greet customers** and welcome them to the flower shop.
- **Recommend flowers** for occasions such as birthdays, anniversaries, weddings, graduations, Valentine's Day, and more.
- **Provide store locations** in Vancouver, Lagos, Abuja, Port Harcourt, and the United States.
- **Answer questions about opening hours.**
- **Respond to thank-you messages and goodbyes.**
- **Handle questions** that fall outside the conversations she was designed for.

## 🖥️ About the Demo

This repository contains a flower shop website with a standalone demo of Florence's conversation flows, based on my exported IBM watsonx Assistant action skill.

The website is a way to showcase the project and make the chatbot experience accessible through a simple web interface.

**Please note:** The chatbot on this demo website is a recreation of selected conversations from my original IBM project. It is not directly connected to the live IBM watsonx Assistant service.

## 🚀 Running the Project

You can try the demo locally:

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start interacting with the chatbot!

No additional installation or build tools are required.

## 🌐 Hosting on GitHub Pages

To publish the website:

1. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the `/(root)` folder.
5. Save and wait for GitHub Pages to publish your site.
